# Setup

1. Run `npm install`.
2. Create `.env` in the project root with your LiveKit project credentials:

   ```dotenv
   LIVEKIT_URL=wss://your-project.livekit.cloud
   LIVEKIT_API_KEY=your-key
   LIVEKIT_API_SECRET=your-secret
   ```

   Keep `.env` out of Git.

3. Run `npm start`.
4. Open http://localhost:3000.
